# 보다보카 (voda-voca)

모바일에 맞춘 웹 기반 영어 단어 학습 서비스입니다. 단어장을 만들고, 단어를 관리하고, 플래시카드와 4지선다 퀴즈로 외우고, 틀린 단어를 북마크해 다시 봅니다.

- **버전**: v2.0.0
- **설계 문서**: [`docs/`](docs/) (요구사항 명세 v2.0, 데이터 설계서 v2.0, API 연동 규격서 v2.0, UI/UX 설계서 v2.0)
- **작업 환경**: Windows 11 + WSL2 (Ubuntu 24.04), Docker

---

## 1. 기술 스택

| 계층 | 기술 | 비고 |
| :--- | :--- | :--- |
| 백엔드 | Python 3.12, FastAPI 0.162, SQLAlchemy 2.1 (asyncmy), Pydantic 2 | 비동기 REST API |
| 마이그레이션 | Alembic 1.20 | 스키마 변경은 마이그레이션으로만 한다 |
| 데이터베이스 | MySQL **8.0** (Docker 컨테이너) | 문자셋 `utf8mb4`, 콜레이션 `utf8mb4_0900_ai_ci` |
| 인증 | 세션 쿠키 (HttpOnly, SameSite=Lax), bcrypt | 세션은 DB `sessions` 테이블에 저장 |
| 프론트엔드 | HTML5, Vanilla JavaScript (ES 모듈, JSDoc), **빌드 없음** | 해시 라우팅, `textContent` 기반 렌더링 |
| UI | Tailwind CSS (Play CDN), SweetAlert2 11.10.5, Lucide 0.460.0 | 디자인: Zinc 뉴트럴 + Indigo 포인트 |
| 테스트 | pytest 9 (백엔드), `node --test` (프론트엔드) | 외부 프론트 의존성 없음 |

프론트엔드에는 npm 의존성이 없습니다. `package.json`은 테스트 실행 스크립트만 가집니다.

### 2.1 아키텍처와 화면 흐름

- **백엔드**: FastAPI가 `/api` 아래 REST API를 제공하고, 같은 출처로 정적 프론트엔드를 서빙합니다. 인증은 세션 쿠키이며, 세션은 DB에 저장합니다.
- **프론트엔드**: 빌드 없는 ES 모듈입니다. 해시 라우팅(`#/…`)으로 화면을 바꾸고, 화면은 `views/`, 순수 로직은 `core/`와 `lib/`에 둡니다. 로직 모듈은 DOM 없이 테스트합니다.
- **화면 흐름**: 로그인·가입 → 단어장 대시보드(요약, 차트, 카드) → 단어장 상세(단어 목록, 검색, 일괄 등록) → 플래시카드 또는 퀴즈 → 학습 이력(오답 복습). 북마크는 별도 탭입니다. 상단 바에는 소리 버튼, 테마 버튼, 계정 칩(드롭다운)이 있습니다.

## 3. 로컬 실행 환경 구축

### 3.1 준비물
- Docker Desktop 또는 Docker Engine (Docker Compose v2)
- Python 3.12
- Node.js (프론트엔드 단위 테스트용, 검증 환경: v26)
- 브라우저 (Chrome, Edge 등 최신 버전)

### 3.2 환경 변수 설정
```bash
cp .env.example .env
```
`.env`에서 다음 값을 실제 값으로 바꿉니다. 이 파일은 저장소에 커밋하지 않습니다.

| 변수 | 설명 |
| :--- | :--- |
| `MYSQL_DATABASE`, `MYSQL_USER`, `MYSQL_PASSWORD` | 애플리케이션 DB 계정 |
| `MYSQL_ROOT_PASSWORD` | MySQL root 비밀번호 (컨테이너 초기화용) |
| `MYSQL_HOST`, `MYSQL_PORT` | 앱이 접속할 DB 주소 (기본 `127.0.0.1:3306`) |
| `COOKIE_SECURE` | HTTP 로컬 개발은 `false`, HTTPS 배포는 `true` |

### 3.3 MySQL 컨테이너 실행
프로젝트 루트에서 실행합니다.
```bash
docker compose --project-directory . -f docker/docker-compose.yml up -d
docker compose --project-directory . -f docker/docker-compose.yml ps   # healthy 가 될 때까지 기다린다
```

### 3.4 Python 가상환경과 패키지
```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
```

### 3.5 데이터베이스 마이그레이션
```bash
.venv/bin/alembic -c src/backend/alembic.ini upgrade head
```
현재 head 는 `aa1c92a9c7f9`입니다. 이미 있는 데이터에 중복 닉네임이 있으면 마이그레이션이 중단되며, 데이터는 바뀌지 않습니다.

### 3.6 서버 실행
```bash
PYTHONPATH=src .venv/bin/uvicorn backend.main:app --reload --port 8000
```
- 웹 앱: http://localhost:8000/
- API 문서(자동 생성): http://localhost:8000/docs
- 헬스체크: http://localhost:8000/health (DB 연결 상태를 `{"status": "ok", "db": "connected"}`로 보여 준다)

처음 방문하면 로그인 화면이 나옵니다. "회원가입"에서 **닉네임과 비밀번호**만 입력하면 가입과 동시에 기본 단어장 3종이 만들어집니다.

## 5. 주요 기능

### 5.1 계정 (REQ-001, REQ-002, REQ-121, REQ-122)
- **닉네임과 비밀번호로 가입**합니다. 이메일은 받지 않습니다. 닉네임은 2~30자이며 대소문자와 무관하게 유일합니다. 비밀번호는 8자 이상, UTF-8 기준 72바이트 이하입니다.
- 로그인 실패가 IP 또는 닉네임 기준 1분에 5회 쌓이면 429로 잠시 막습니다 (무차별 대입 방어). 대기 시간은 카운트다운으로 보여 줍니다.
- **회원 탈퇴**는 계정 메뉴(상단 닉네임 칩)에서 합니다. 경고를 확인한 뒤 닉네임을 직접 입력해야 탈퇴가 진행되며, 계정과 모든 단어장, 단어, 북마크, 학습 기록이 영구 삭제됩니다.

### 5.2 기본 단어장 (REQ-123)
가입 직후 다음 단어장 3개가 자동으로 만들어집니다. 각 단어장에는 표제어, 뜻, 예문이 있는 단어 200개가 들어 있습니다.

| 단어장 | 대상 |
| :--- | :--- |
| 초급 필수 영단어 200 | 일상에서 자주 쓰는 기초 어휘 |
| 중급 핵심 영단어 200 | 중학교 수준 핵심 어휘 |
| 고급 심화 영단어 200 | 고등학교 이상 심화 어휘 |

합계 600단어입니다. 원본은 `src/backend/data/seeds/`의 JSON 파일입니다. 기본 단어장도 일반 단어장처럼 수정하고 삭제할 수 있습니다.

### 5.3 단어장과 단어 (REQ-004~011)
- 단어장을 만들고, 이름과 설명을 고치고, 삭제합니다. 삭제하면 안의 단어, 북마크, 학습 기록이 함께 지워지며, 확인 창에 이 내용을 안내합니다.
- 단어를 추가, 수정, 삭제합니다. 같은 단어장 안에서 표제어는 중복할 수 없습니다.
- **표제어 실시간 검색**: 검색창에 입력하면 **300ms 디바운스** 뒤에 접두사 검색을 합니다. 이전 요청은 취소하고, 늦게 온 응답은 버립니다.

### 5.4 일괄 등록 (REQ-008)
- 단어장 상세의 **[일괄 등록]**에서 CSV 또는 TSV 파일을 고르거나 직접 붙여넣을 수 있습니다.
- 한 줄에 `표제어,뜻` 또는 `표제어,뜻,예문` 형식입니다. 헤더 줄은 자동으로 건너뜁니다. 따옴표로 감싼 값, UTF-8 BOM, CRLF를 처리합니다.
- 전송 전에 미리보기로 오류를 보여 줍니다. 한 번에 최대 100건이며, 하나라도 기존 표제어와 겹치면 전부 취소됩니다 (All-or-Nothing). 어느 표제어가 겹쳤는지 표시합니다.

### 5.5 플래시카드 (REQ-012, REQ-013, REQ-019)
- 카드를 누르면 3D로 뒤집혀 뜻과 예문이 보입니다.
- 좌우로 밀어서 넘기거나 키보드 ← → 로 넘깁니다. Space 또는 Enter 로 뒤집습니다.
- 셔플을 켜면 무작위 순서로 보고, 보던 카드는 그대로 유지됩니다.
- 단어장 또는 북마크 단어 전체를 대상으로 합니다.

### 5.6 4지선다 퀴즈 (REQ-014~016, REQ-019, REQ-124)
- 원천 단어가 4개 미만이면 퀴즈를 시작할 수 없고, 이유를 안내합니다.
- 문항 수는 5, 10, 20 중에서 고르며, 단어가 부족하면 가능한 만큼 출제합니다.
- **즉각 피드백**: 보기를 누르는 즉시 정답은 초록, 내가 고른 틀린 답은 빨강으로 표시합니다. 정답 뜻과 **해설 예문** 카드가 나타나고, [다음 문항]으로 넘어갑니다. 한 문항은 한 번 고르면 바뀌지 않습니다.
- 30분 세션 타이머가 있습니다. 시간이 지나면 더 이상 답할 수 없습니다.
- 마지막 문항 뒤 [최종 결과 보기]로 기록을 저장하고, 정답 수, 정답률, 오답 노트를 보여 줍니다.
- 결과는 같은 탭에서 새로고침해도 남습니다 (세션 저장소에 캐싱).

### 5.7 북마크 모아보기 (REQ-017, REQ-018)
- 단어장과 학습 화면에서 별을 눌러 북마크합니다. 북마크 화면에서는 최신순으로 모아 봅니다.
- 별을 끄면 목록에서 바로 사라집니다. 서버 저장이 실패하면 원래대로 되돌립니다.
- 북마크 단어로 플래시카드와 퀴즈를 시작할 수 있습니다. 북마크가 4개 미만이면 퀴즈는 비활성입니다.

### 5.8 학습 이력 (REQ-016, REQ-129)
- 최근 학습 기록 100건을 날짜별 타임라인으로 보여 줍니다. 정답과 오답을 표시하고, 시각은 한국 시간입니다.
- 상단에 최근 100건의 정답률을 보여 줍니다.
- **오답 복습 퀴즈 시작**: 최근 100건에서 틀린 고유 단어가 4개 이상이면 버튼이 켜집니다. 같은 단어를 여러 번 틀려도 문항은 한 번만 나옵니다. 4개 미만이면 버튼이 꺼지고 현재 개수를 안내합니다.

### 5.9 추천 1,000제 (REQ-130)
- 단어장 화면의 **추천 1,000제 추가**를 누르고 확인하면 "중급 필수 영단어 1,000" 단어장이 내 계정에 만들어집니다. 단어 1,000개가 한 번에 들어갑니다.
- 같은 이름의 단어장이 이미 있으면 추가되지 않습니다. 데이터 파일이 없으면 "준비되지 않았습니다"라고 안내합니다.
- 원본은 `src/backend/data/seeds/intermediate_1000.csv`입니다. 첫 줄 헤더는 `term,meaning,example,example_meaning`(예문 뜻 포함, 현행)이어야 합니다. 3열(`term,meaning,example`) 형식도 읽을 수 있습니다. 파일을 고치면 서버를 다시 띄우지 않아도 다음 요청부터 반영됩니다.

### 5.10 추천 학습 흐름
1. 가입하면 기본 단어장 3종(초급·중급·고급 200제)이 생깁니다.
2. 필요하면 **추천 1,000제**를 추가합니다.
3. 단어장을 열고 **플래시카드**로 훑습니다. 스피커 버튼으로 발음을 듣고, 셔플로 순서를 섞을 수 있습니다.
4. **4지선다 퀴즈**를 풉니다. 보기를 누르면 바로 정오와 해설 예문이 나옵니다.
5. **학습 이력**에서 틀린 단어가 4개 이상이면 **오답 복습 퀴즈**로 다시 풉니다.
6. 기억이 흐린 단어는 별을 눌러 **북마크**해 두고, 북마크 단어로 플래시카드나 퀴즈를 시작합니다.

---

### 5.11 학습 대시보드 (REQ-131~133)
- 단어장 화면 맨 위에 **총 단어 수, 정답률, 연속 학습일** 요약 카드를 보여 줍니다. 정답률과 연속 학습일은 최근 100건의 학습 기록으로 계산합니다.
- **최근 7일 차트**에서 날짜마다 학습한 단어 수를 보여 줍니다. 같은 단어를 같은 날 여러 번 풀어도 한 번으로 셉니다. 오늘 막대는 진하게, "오늘" 뱃지와 함께 표시합니다.
- 단어장 카드에는 성격 태그, 학습 진행률 바, 플래시카드와 퀴즈 바로 가기가 있습니다. 진행률은 그 단어장의 단어 중 정답 이력이 있는 단어의 비율입니다.

### 5.12 계정 메뉴와 CSV 내보내기 (REQ-134~136, REQ-139)
- 닉네임 칩을 누르면 칩 아래에 메뉴가 뜹니다. 로그아웃은 확인 후 처리하고, 회원 탈퇴는 두 단계 확인을 거칩니다.
- **내 단어장 백업**은 바로 받지 않고 내보내기 모달을 엽니다. "전체 단어장 합본"(`단어장,표제어,뜻,예문,예문 뜻`)이나 "개별 단어장 선택"(`표제어,뜻,예문,예문 뜻`)을 고르고 [내보내기]를 눌러야 받습니다.
- 단어장 카드의 내보내기 버튼은 단어 수를 밝힌 확인 후 `[단어장_이름]_YYYYMMDD.csv`를 받습니다.
- 내보낸 개별 단어장 파일은 **일괄 등록으로 다시 가져올 수 있습니다.** 예문 뜻 열이 포함되어도 오류가 나지 않습니다.
- 모든 파일은 UTF-8 BOM으로 저장하므로 엑셀에서 한글이 깨지지 않습니다.

### 5.13 정답 효과음과 소리 끄기 (REQ-137, REQ-138)
- 퀴즈에서 정답을 고르면 두 음(D5에서 A5로 올라가는 짧은 음)이 납니다. Web Audio API로 합성하므로 음원 파일을 내려받지 않습니다.
- 오답을 고르면 소리가 나지 않습니다.
- 헤더의 스피커 버튼으로 끄고 켭니다. 설정은 브라우저에 저장되며, 기본값은 켬입니다.

## 6. 보안과 운영 메모
- 세션 쿠키는 JavaScript 에서 읽을 수 없습니다 (HttpOnly). 토큰 원문은 저장하지 않고 SHA-256 값만 DB 에 둡니다.
- 비밀번호는 bcrypt 로 해시합니다. 평문은 저장하지 않습니다.
- 모든 SQL 은 파라미터 바인딩을 씁니다. LIKE 검색어의 특수 문자는 이스케이프합니다.
- 단어, 단어장, 북마크, 학습 기록은 사용자별로 격리됩니다. 다른 사용자의 리소스는 404 로 응답합니다.
- 로그인 무차별 대입 방어는 프로세스 메모리에서 동작합니다. 워커를 여러 개 띄우면 한도가 워커마다 따로 적용되므로, 그 경우 공유 저장소가 필요합니다.
- 프론트엔드는 `innerHTML`을 쓰지 않고 `textContent`로만 텍스트를 넣습니다.
- 퀴즈 출제 응답에는 정답 인덱스가 포함됩니다 (즉각 피드백). 학습 기록의 신뢰도가 중요한 용도로 쓰려면 이 점을 고려해야 합니다.

## 7. 알려진 제한
- 진행 중인 퀴즈는 새로고침하면 사라집니다. 세션 조회 API 가 없습니다.
- 결과 캐시는 같은 탭 안에서만 유지됩니다.
- 대시보드의 통계와 진행률은 **최근 100건** 학습 기록 기준입니다. 학습 이력 API의 최대 건수가 100이기 때문입니다. 누적 통계에는 백엔드 집계 엔드포인트가 필요합니다.
- 일괄 등록 미리보기 표에는 아직 예문 뜻을 표시하지 않습니다. 전송 본문에는 포함됩니다.
- 전체 합본 백업은 단어장 이름 열이 있어 일괄 등록으로 다시 가져올 수 없습니다. 개별 단어장 파일을 사용하세요.
- 정답 소리는 브라우저 정책에 따라 첫 사용자 동작 뒤부터 날 수 있습니다.
- 설계서가 가정한 HTTPS 배포와 워커 다중화 설정은 아직 문서화된 운영 절차가 없습니다.
