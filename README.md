# 보다보카 (voda-voca)

모바일에 맞춘 웹 기반 영어 단어 학습 서비스입니다. 서비스가 준비한 **표준 단어장**(5종, 1,000단어)을 골라 학습 세션 하나에서 4지선다 퀴즈와 플래시카드로 외우고, 북마크와 틀린 단어를 복습함에서 다시 봅니다.

- **버전**: v2.2 개발 중 (최근 릴리즈 태그 `v2.1.0`)
- **설계 문서**: [`docs/`](docs/) (요구사항 명세 v2.1, 데이터 설계서 v2.1, API 연동 규격서 v2.1, UI/UX 설계서 v2.2)
- **작업 환경**: Windows 11 + WSL2 (Ubuntu 24.04), Docker

---

## 1. 기술 스택

| 계층 | 기술 | 비고 |
| :--- | :--- | :--- |
| 백엔드 | Python 3.12, FastAPI 0.162, SQLAlchemy 2.1 (asyncmy), Pydantic 2 | 비동기 REST API |
| 마이그레이션 | Alembic 1.20 | 스키마 변경은 마이그레이션으로만 한다 |
| 데이터베이스 | MySQL **8.0** (Docker 컨테이너) | 문자셋 `utf8mb4`, 콜레이션 `utf8mb4_0900_ai_ci`, 시간대 Asia/Seoul |
| 인증 | 세션 쿠키 (HttpOnly, SameSite=Lax), bcrypt | 세션은 DB `sessions` 테이블에 저장 |
| 프론트엔드 | HTML5, Vanilla JavaScript (ES 모듈, JSDoc), **빌드 없음** | 해시 라우팅, `textContent` 기반 렌더링 |
| UI | Tailwind CSS (Play CDN), SweetAlert2 11.10.5, Lucide 0.460.0 | Zinc 뉴트럴 + Indigo 포인트, 다크 모드 |
| 서체 | Pretendard Variable (본문), Paperlogy Bold (제목·학습 단어) | CDN, `font-display: swap`, 실패 시 시스템 폰트 |
| 테스트 | pytest 9 (백엔드), `node --test` (프론트엔드) | 외부 프론트 의존성 없음 |

프론트엔드에는 npm 의존성이 없습니다. `package.json`은 테스트 실행 스크립트만 가집니다.

### 2.1 아키텍처와 화면 흐름

- **백엔드**: FastAPI가 `/api` 아래 REST API를 제공하고, 같은 출처로 정적 프론트엔드를 서빙합니다. 인증은 세션 쿠키이며 세션은 DB에 저장합니다. 서버가 시작될 때 표준 단어장 시드를 DB에 반영합니다.
- **표준 단어장**: 단어장과 단어는 서비스가 제공하는 **읽기 전용 공용 콘텐츠**입니다. 사용자가 만들거나 고치지 않으며, 사용자별로는 활성 단어장, 북마크, 학습 기록, 단어 진행도, 학습 설정만 저장합니다.
- **프론트엔드**: 빌드 없는 ES 모듈입니다. 해시 라우팅(`#/…`)으로 화면을 바꾸고, 화면은 `views/`, DOM 없는 순수 로직은 `core/`에 둡니다.
- **하단 탭 4개**: 홈 · 탐색 · 복습함 · 통계. 학습 세션(`#/study/session`)은 탭이 아니며 세션 중에는 탭바가 숨겨집니다.
- **화면 흐름**: 로그인·가입 → 탐색에서 단어장을 고름 → 홈에서 "N문항 학습 시작" → 학습 세션(퀴즈 또는 플래시카드) → 결과. 복습함에서 북마크·틀린 단어로 같은 세션을 시작합니다.
- **상단바**: 브랜드와 계정 칩이 있습니다. 계정 메뉴에 **학습 설정**, **환경 설정**, **로그아웃**, **회원 탈퇴**가 있습니다.

## 3. 로컬 실행 환경 구축

### 3.1 준비물
- Docker Desktop 또는 Docker Engine (Docker Compose v2)
- Python 3.12
- Node.js (프론트엔드 단위 테스트용, 검증 환경: v26)
- 브라우저 (Chrome, Edge 등 최신 버전)

### 3.2 환경 변수 설정
```bash
cp .env.example .env
```
`.env`에서 다음 값을 실제 값으로 바꿉니다. 이 파일은 저장소에 커밋하지 않습니다.

| 변수 | 설명 |
| :--- | :--- |
| `MYSQL_DATABASE`, `MYSQL_USER`, `MYSQL_PASSWORD` | 애플리케이션 DB 계정 |
| `MYSQL_ROOT_PASSWORD` | MySQL root 비밀번호 (컨테이너 초기화용) |
| `MYSQL_HOST`, `MYSQL_PORT` | 앱이 접속할 DB 주소 (기본 `127.0.0.1:3306`) |
| `TZ` | 시간대 (기본 `Asia/Seoul`) |
| `COOKIE_SECURE` | HTTP 로컬 개발은 `false`, HTTPS 배포는 `true` |

### 3.3 MySQL 컨테이너 실행
프로젝트 루트에서 실행합니다.
```bash
docker compose --project-directory . -f docker/docker-compose.yml up -d
docker compose --project-directory . -f docker/docker-compose.yml ps   # healthy 가 될 때까지 기다린다
```

### 3.4 Python 가상환경과 패키지
```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
```

### 3.5 데이터베이스 마이그레이션
```bash
.venv/bin/alembic -c src/backend/alembic.ini upgrade head
```
현재 head 는 `e2b6d4a9f1c3`입니다.

### 3.6 서버 실행
```bash
PYTHONPATH=src .venv/bin/uvicorn backend.main:app --reload --port 8000
```
- 웹 앱: http://localhost:8000/
- API 문서(자동 생성): http://localhost:8000/docs
- 헬스체크: http://localhost:8000/health (DB 연결 상태를 `{"status": "ok", "db": "connected"}`로 보여 준다)

> **시드 자동 적재**: 서버가 시작(또는 리로드)될 때 `src/backend/data/seeds/`의 표준 단어장을 DB에 INSERT/UPDATE 합니다. 시드 파일을 고치거나 추가하기 전에 DB를 백업하세요.

처음 방문하면 로그인 화면이 나옵니다. "회원가입"에서 **닉네임과 비밀번호**만 입력해 가입하고, 탐색에서 단어장을 고르면 학습을 시작할 수 있습니다.

## 5. 주요 기능

### 5.1 계정 (REQ-001, REQ-002, REQ-121, REQ-122)
- **닉네임과 비밀번호로 가입**합니다. 이메일은 받지 않습니다. 닉네임은 2~30자이며 대소문자와 무관하게 유일합니다. 비밀번호는 8자 이상, UTF-8 기준 72바이트 이하입니다.
- 로그인 실패가 IP 또는 닉네임 기준 1분에 5회 쌓이면 429로 잠시 막습니다 (무차별 대입 방어). 대기 시간은 카운트다운으로 보여 줍니다.
- 로그아웃은 확인 없이 바로 처리합니다. **회원 탈퇴**는 경고를 확인한 뒤 닉네임을 직접 입력해야 진행되며, 계정과 북마크, 학습 기록, 진행도가 영구 삭제됩니다 (표준 단어장은 공용이라 영향이 없습니다).

### 5.2 표준 단어장과 탐색 (REQ-140~142, REQ-145)
- 서비스가 제공하는 단어장 5개, 단어 1,000개입니다. 각 단어에는 표제어, 뜻, 예문, 예문 해석, 발음기호, 품사가 있습니다.

| 단어장 | 카테고리 | 대상 |
| :--- | :--- | :--- |
| 초급 필수 영단어 200 | 초등 | 일상에서 자주 쓰는 기초 어휘 |
| 중급 핵심 영단어 200 | 중고등 | 중학교 수준 핵심 어휘 |
| 고급 심화 영단어 200 | 수능 | 고등학교 이상 심화 어휘 |
| 시험 대비 핵심 200 | 시험 | 시험 대비 핵심 어휘 |
| 실무 비즈니스 영단어 200 | 비즈니스 | 직장 영어 어휘 |

- **탐색** 탭에서 카테고리·레벨 칩으로 거르고, 카드의 [미리보기]로 단어를 읽기 전용으로 훑습니다 (30개씩 "더 보기"). [이 단어장으로 학습]을 누르면 그 단어장이 **활성 단어장**이 됩니다.
- 원본은 `src/backend/data/seeds/`의 JSON 파일입니다. 값이 바뀌면 서버가 다시 뜰 때 DB에 반영됩니다.

### 5.3 홈과 학습 세션 (REQ-012, REQ-014~016, REQ-124, REQ-142, REQ-147)
- **홈**은 세션 시작까지 한 번의 탭이 목표입니다. 활성 단어장과 진행률, 오늘의 목표, 퀴즈/플래시카드 토글, "N문항 학습 시작" 버튼이 있습니다. 오늘 학습 수는 고유 단어 기준입니다.
- 한 번에 푸는 문항 수와 오늘의 목표는 **학습 설정**(10·20·30, 기본 10)을 따릅니다.
- **세션 하나에서 퀴즈와 플래시카드를 모두 진행**합니다. 문항마다 서버가 즉시 채점·기록하며, 한 번 고른 답은 바뀌지 않습니다.
- **퀴즈(4지선다)**: 단어를 보고 알맞은 뜻을 고릅니다. 고르면 해설 시트가 올라와 정오, 뜻, 예문, 품사와 발음기호를 보여 줍니다. 단어 4개 미만이면 출제할 수 없습니다.
- **플래시카드**: 앞면에 표제어·품사·발음기호, 뒷면에 뜻·예문을 보여 줍니다. 카드를 눌러 뒤집고 "헷갈려요"/"알아요"로 평가합니다.
- **숙련**: 한 단어를 연속 3번 맞히면 숙련으로 표시하고 기본 출제에서 뺍니다. 한 번 틀리면 숙련이 풀립니다.
- **콤보와 효과음**: 연속 정답이 2 이상이면 콤보 뱃지가 보이고 5·10·15에서 마일스톤 소리가 납니다. 효과음은 Web Audio로 합성하므로 음원 파일이 없습니다.
- **발음 듣기**: 스피커 버튼이 브라우저 음성 합성(Web Speech API)으로 읽습니다. 지원하지 않으면 한 번만 안내하고 조용히 넘어갑니다.
- **키보드 단축키**: 플래시카드는 Space·Enter 뒤집기, ←/→ 평가. 퀴즈는 숫자 키로 고르고 Enter·Space로 다음 문항. Esc는 세션 중단 확인 모달을 엽니다.
- **세션 중 북마크**: 카드 오른쪽 위 별 버튼으로 북마크합니다. 응답을 기다리지 않고 바로 바뀌고, 실패하면 되돌리고 토스트로 알립니다.

### 5.4 복습함 (REQ-017~019, REQ-129)
- **북마크**와 **틀린 단어** 두 탭이 있고, 각각 20건씩 "더 보기"로 이어 받습니다. 행에는 표제어, 품사, 발음기호, 단어장 이름, 뜻이 보입니다 (예문은 보이지 않습니다).
- **틀린 단어**는 단어별 **마지막 결과가 오답**인 단어입니다. 다시 맞히면 목록에서 빠집니다.
- 해당 목록의 단어가 **4개 이상**이면 [복습 시작]이 켜지고, 그 단어들로 같은 학습 세션(퀴즈 또는 플래시카드)을 시작합니다. 복습은 활성 단어장을 바꾸지 않습니다.

### 5.5 통계 (REQ-131~133)
- 누적 정답률, 연속 학습일(한국 날짜 기준), 최근 7일 학습 단어 수 막대 차트(오늘 강조), 단어장별 숙련도 진행률을 보여 줍니다. 전체 이력 기준이며 서버가 집계합니다.

### 5.6 계정 메뉴, 학습 설정, 환경 설정 (REQ-134, REQ-147, REQ-149)
- 닉네임 칩을 누르면 칩 아래에 메뉴가 뜹니다. 바깥을 누르거나 Esc로 닫습니다.
- **학습 설정**(책 아이콘): 퀴즈 문항 수, 플래시카드 문항 수, 오늘의 목표를 칩으로 고릅니다. 고르는 즉시 서버(`/api/users/me/settings`)에 저장하고 실패하면 되돌립니다.
- **환경 설정**(톱니바퀴 아이콘): 스위치로 **효과음**과 **다크 모드**를 켜고 끕니다. 두 값은 이 브라우저에 저장합니다 (`voda.sound_muted`, `voda.theme`). 다크 모드는 저장값이 없으면 시스템 설정을 따릅니다. 효과음은 발음 듣기와 별개입니다.
- 로그인 전 화면(로그인·가입)에는 계정 메뉴가 없어서 다크 모드를 바꿀 수 없습니다. 저장값이나 시스템 설정을 따릅니다.

### 5.7 추천 학습 흐름
1. 가입하고 **탐색**에서 학습할 단어장을 고릅니다 (미리보기로 단어를 먼저 볼 수 있습니다).
2. **홈**에서 모드(퀴즈 또는 플래시카드)를 고르고 "N문항 학습 시작"을 누릅니다.
3. 퀴즈 해설과 플래시카드 뒷면에서 뜻과 예문, 발음기호를 확인합니다. 스피커 버튼으로 발음을 듣습니다.
4. 기억이 흐린 단어는 카드의 별 버튼으로 **북마크**합니다.
5. **복습함**에서 북마크나 틀린 단어가 4개 이상이면 [복습 시작]으로 다시 풉니다.
6. **통계**에서 정답률, 연속 학습일, 단어장 진행률을 확인합니다.

## 6. API 개요

모든 경로는 `/api` 아래입니다. 자세한 요청·응답은 `docs/voda-voca_API_Integration_Spec_v2.1_261105.md`와 `/docs`(자동 생성)를 봅니다.

| 영역 | 엔드포인트 |
| :--- | :--- |
| 인증 | `POST /auth/signup`, `POST /auth/login`, `POST /auth/logout`, `GET·DELETE /auth/me` |
| 표준 단어장 | `GET /vocabularies`, `GET /vocabularies/{id}/words`, `POST /users/me/active-vocabulary` |
| 학습 세션 | `POST /study/sessions`, `POST /study/sessions/{id}/answer` (`mode=quiz\|flashcard`, `source=all\|bookmarks\|wrong`) |
| 북마크 | `PUT·DELETE /bookmarks/{word_id}`, `GET /bookmarks` |
| 복습·통계 | `GET /study/wrong-words`, `GET /study/stats`, `GET /study/logs` |
| 사용자 설정 | `GET·PATCH /users/me/settings` |

## 7. 보안과 운영 메모
- 세션 쿠키는 JavaScript 에서 읽을 수 없습니다 (HttpOnly). 토큰 원문은 저장하지 않고 SHA-256 값만 DB 에 둡니다.
- 비밀번호는 bcrypt 로 해시합니다. 평문은 저장하지 않습니다.
- 모든 SQL 은 파라미터 바인딩을 씁니다.
- 북마크, 학습 기록, 진행도, 설정은 사용자별로 격리됩니다.
- 로그인 무차별 대입 방어는 프로세스 메모리에서 동작합니다. 워커를 여러 개 띄우면 한도가 워커마다 따로 적용되므로, 그 경우 공유 저장소가 필요합니다.
- 프론트엔드는 `innerHTML`을 쓰지 않고 `textContent`로만 텍스트를 넣습니다.
- 퀴즈 출제 응답에는 정답 인덱스가 포함됩니다 (즉각 피드백). 학습 기록의 신뢰도가 중요한 용도로 쓰려면 이 점을 고려해야 합니다. 대신 발음기호는 출제 응답에서 서버가 비웁니다.

## 8. 알려진 제한
- 진행 중인 세션을 다시 조회하는 API 가 없어 새로고침하면 이어갈 수 없습니다. 이미 푼 문항은 문항마다 서버에 기록되어 통계에 남습니다.
- 효과음 설정과 다크 모드 선택은 **브라우저별**로 저장되어 다른 기기와 공유되지 않습니다. 학습 설정(문항 수·목표)은 서버에 저장됩니다.
- 로그인·가입 화면에서는 다크 모드를 직접 바꿀 수 없습니다 (환경 설정이 계정 메뉴에 있음).
- 제목 폰트(Paperlogy)의 상업적 사용 라이선스는 배포 전에 확인해야 합니다.
- 효과음은 브라우저 정책에 따라 첫 사용자 동작 뒤부터 날 수 있습니다. 발음 듣기는 브라우저에 영어 음성이 없으면 동작하지 않습니다.
- 모바일 실제 기기에서의 시각 점검(360px 레이아웃, 다크 모드의 북마크 색, 발음기호 글리프)은 자동 테스트로 확인할 수 없어 수동 점검 대상입니다.
- 설계서가 가정한 HTTPS 배포와 워커 다중화 설정은 아직 문서화된 운영 절차가 없습니다.
