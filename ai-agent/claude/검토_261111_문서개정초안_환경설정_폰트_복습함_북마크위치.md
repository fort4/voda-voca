## 1. UI/UX 설계서 개정안

### 1.1 §3.4 복습함 (REQ-017, 018, 019, 129)

`행` 줄을 교체한다.

- 현재: `- **행**: 표제어, 뜻, 소속 단어장 제목, 예문(있을 때만), 예문 뜻(있을 때만).`
- 개정: `- **행** (2026-11-11 개정): 표제어 · 품사(`.pos-tag`) · /발음기호/(`.phonetic`)를 한 줄(`flex-wrap`, 좁으면 줄바꿈)에 놓고, 오른쪽에 소속 단어장 제목, 아래 줄에 뜻을 보입니다. **예문과 예문 뜻은 보이지 않습니다.** 품사·발음기호는 값이 없으면 요소를 그리지 않습니다. 단어 시트와 같은 컴포넌트(`pos-tag.js`, `phonetic-line.js`)를 씁니다. 복습함은 단어 목록 조회라 퀴즈 출제 응답의 발음기호 비노출 규칙(§12.8)과 무관합니다.`

### 1.2 §3.6 학습 세션 — 효과음 토글, 플래시카드

- `효과음 토글` 줄 (§3.6) 교체:
  - 개정: `- **효과음 토글** (2026-11-11 개정): 앱 헤더 버튼을 없애고 계정 메뉴의 **환경 설정** 모달(§12.12)로 옮겼습니다. 세션 진행 헤더에는 예전처럼 두지 않습니다. 발음(TTS) 버튼은 `volume-2` 로 아이콘이 다릅니다.`
- 플래시카드 북마크(§3.6 의 해당 언급이 있다면 같은 취지로): 버튼은 앞·뒷면에 각각 있고 카드와 함께 뒤집힌다 (상세 §1.7).

### 1.3 §3.7 · §3.7.1 계정 메뉴

- §3.7 `진입` 줄: `메뉴에는 **학습 설정**, **환경 설정**, **로그아웃**, **회원 탈퇴**가 있습니다.`
- §3.7.1 `구성` 줄을 다음 순서로 고친다:
  `프로필 헤더(…) → 구분선 → **학습 설정**(`book-open`, 누르면 메뉴를 닫고 설정 모달을 연다, §12.10) → **환경 설정**(`settings`, 메뉴를 닫고 환경 설정 모달을 연다, §12.12) → 구분선 → **로그아웃**(…) → 구분선 → 위험 구역의 **회원 탈퇴**(…)`
  - 학습 설정과 환경 설정은 같은 묶음이라 둘 사이에 구분선을 두지 않는다 (구현 그대로).
- **알려진 제약 (신규 문단)**: 헤더에는 더 이상 다크 모드·효과음 버튼이 없다. 로그인·회원가입 화면에서는 계정 메뉴가 없으므로 다크 모드를 **전환할 수 없고**, 저장된 선택(`voda.theme`) 또는 시스템 설정을 따른다. 전환은 로그인 후 환경 설정에서 한다.

### 3.9 REQ-149 신설 (기능 요구사항 표, REQ-148 다음 행)

`| REQ-149 | 환경 설정 | S | (v2.2) 사용자가 효과음과 다크 모드를 계정 메뉴의 **환경 설정** 모달에서 바꾼다. ① **진입**: 상단바 계정 메뉴의 "환경 설정"(학습 설정 바로 아래). 헤더에는 효과음·다크 모드 버튼을 두지 않는다. ② **구성**: 효과음·다크 모드 두 행의 스위치(`role="switch"`, `aria-checked`). 누르면 즉시 적용·저장하고 확인 버튼 없이 "닫기"만 둔다. 효과음은 `voda.sound_muted`(기본 켬), 다크 모드는 `voda.theme`(없으면 시스템 설정)에 저장한다 — REQ-138·REQ-126 과 같은 저장소다. ③ **동기화**: 효과음은 엔진 구독으로 어디서 바뀌어도 스위치가 따라온다. 모달을 닫을 때 구독을 해제한다. ④ **터치·접근성**: 행 높이 44px 이상, 행 전체가 스위치라 라벨과 설명을 함께 낭독한다. ⑤ **제약**: 로그인 상태에서만 열 수 있어 로그인·회원가입 화면에서는 다크 모드를 전환할 수 없다(저장값·시스템 설정은 적용). ⑥ **모션**: 모달 등장·퇴장은 오버슈트 없는 220ms/140ms 페이드+이동이고 `prefers-reduced-motion` 에서는 끈다(UI/UX 설계서 §9). |`
