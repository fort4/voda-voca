## 2. REQ-168 퀴즈 가중 무작위 출제 (S)

(VOCA-FR-022, 이슈 #34) 활성 단어장 퀴즈(`mode=quiz`, `source=all`)는 REQ-012·129·150 의 배분(오답 상한 30%, 복습 10% 선확보, 미학습 충원)을 유지하고, **각 묶음 안에서는 가중 무작위**(중복 없이)로 고른다.

1. 가중치 = `(1 + min(누적 오답 횟수, 5)) × (10 + min(마지막 학습 뒤 지난 일수, 30))`. 범위 10~240 이다. 일수는 24시간 단위이며, 학습 시각이 없는 옛 기록은 30일로 본다.
2. 많이 틀렸거나 오래 안 본 단어일수록 뽑힐 확률이 높다. 어떤 단어도 확률이 0 이 되지 않는다.
3. 미학습 단어는 모두 같은 가중치로 무작위다 (등록 순서가 아니다).
4. 복습 묶음은 **기한이 지난 단어를 먼저** 채우는 REQ-150 규칙을 유지한다. 기한 지난 단어끼리, 기한 전 단어끼리 가중 무작위다.
5. 바꾸지 않는 것: 플래시카드(미학습은 `order_index` 순, 오답은 최근 순), 북마크·오답·오늘 복습 세션(균등 무작위), 문항 수, API 요청·응답, DB 구조.

## 3. 설계

| 파일 | 변경 |
| :--- | :--- |
| `services/session_picker.py` | `study_weight`, `candidate_weights`, `weighted_order` 추가. `select_session_words` 에 선택 인자 `weights` (없으면 기존 동작) |
| `services/learning_session.py` | 퀴즈일 때만 `weights` 를 넘긴다 |

가중 비복원 추출은 Efraimidis–Spirakis 방식이다. 항목마다 `log(u) / w` (u 는 (0,1] 난수)를 만들어 큰 순으로 세우면, 앞에서부터 뽑는 것이 가중치에 비례한 비복원 추출과 같다. 정렬 한 번이라 단순하고, `rng` 를 주면 결과가 재현된다. 기존 배분 코드는 "목록의 앞에서부터 뽑는다"는 구조라 목록 순서만 바꾸면 된다.
