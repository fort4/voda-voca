## 1. 알고리즘
- 단계 0~5, 간격표: 0=즉시, 1=1일, 2=3일, 3=7일, 4=14일, 5=30일.
- 정답: 단계 +1 (최대 5), `next_review_at = now + 새 단계 간격`.
- 오답: 단계 −2 (최소 0) 부분 감쇠, `next_review_at = now + 새 단계 간격`.
- 순수 함수 `schedule_next(step, is_correct, now) -> (step, next_review_at)`. DB·시계 비의존.

## 2. 스키마
- `user_word_progress.interval_step TINYINT UNSIGNED NOT NULL DEFAULT 0`
- `user_word_progress.next_review_at DATETIME(3) NULL` + 인덱스 `idx_uwp_user_next_review (user_id, next_review_at)`
- 백필: 학습 이력이 있는 행은 `interval_step = LEAST(consecutive_correct_count, 5)`, `next_review_at = last_studied_at + 해당 단계 간격`.

## 3. 결정 사항
- `is_memorized`는 이번 범위에서 기존 규칙(연속 정답 3회)을 유지한다. 단계로 흡수하면 출제가 바뀌므로 출제 연동 작업(4단계)에서 함께 정한다.
- 오답 감쇠 −2는 상수(`WRONG_STEP_PENALTY`)로 두어 조정 가능하게 한다.
