# 검토 — 로그인 전 헤더 다크 모드 버튼의 `docs/` 반영 초안

`docs/` 는 승인 후에만 수정하므로 승인되면 아래대로 반영하고 변경 이력 행을 추가한다. (구현·테스트는 완료: node 468건 통과)

## 변경 요약
- 로그아웃 상태 상단바에서 **로그인 링크 왼쪽**에 다크 모드 전환 버튼(44px 아이콘 버튼)을 둔다. 로그인 후에는 지금처럼 계정 메뉴의 환경 설정에서 바꾼다(헤더 버튼 없음).
- 아이콘·라벨은 **누르면 바뀔 모드**를 보여 준다: 라이트면 `moon` + "다크 모드로 전환", 다크면 `sun` + "라이트 모드로 전환" (`themeToggleView`). 환경 설정 모달의 행 아이콘이 *현재 상태*를 보이는 것과 다르다(글자 없는 아이콘 버튼이라 행동을 알려야 함).
- 저장은 기존과 같은 `voda.theme` 이다. 누르면 즉시 적용·저장하고 헤더를 다시 그려 아이콘을 맞춘다. 로그인해도 선택이 이어진다.

## 반영 대상
1. **UIUX_Design_Spec_v2.2_261105.md §12.12** "알려진 제약" 줄(215행)을 교체:
   `헤더에는 더 이상 다크 모드·효과음 버튼이 없습니다. 로그인·회원가입 화면에서는 ... 전환할 수 없고 ... 전환은 로그인 후 환경 설정에서 합니다.` →
   `로그인 후 헤더에는 다크 모드·효과음 버튼이 없고 계정 메뉴의 환경 설정에서 바꿉니다. 로그인 전(로그인·회원가입 포함)에는 계정 메뉴가 없으므로 상단바 로그인 링크 왼쪽의 다크 모드 버튼(44px, 라이트면 moon, 다크면 sun, 라벨 "다크 모드로 전환"/"라이트 모드로 전환")으로 전환합니다 (2026-11-19).`
   + 변경 이력 행 `v2.2 개정 | 2026-11-19 | 로그인 전 헤더 다크 모드 버튼(§12.12, REQ-126)`
2. **Requirement_Spec_v2.2_261119.md REQ-126**(§4.6): "로그인 전 화면에서는 로그인 링크 왼쪽 버튼으로 전환한다" 문장 추가, 변경 이력 행 추가. 매트릭스 REQ-126 구현 위치에 `app.js`, `core/preferences-model.js`(`themeToggleView`) 추가.

## 열린 점
- 브라우저가 없어 실제 렌더링(버튼 위치·아이콘 전환·360px 겹침)은 자동 검증하지 못했다. 모바일 점검 체크리스트에 항목을 추가할 것: "로그인 전 360px 헤더에서 달/해 버튼과 '로그인'이 겹치지 않고, 누르면 즉시 바뀌며 아이콘이 따라 바뀐다".
