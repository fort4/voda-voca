## 2. 고칠 위치

- §12 표 "다크 모드": "Zinc 계열만 쓴다" 를 표면 계층(`--bg` < `--surface` < `--control` < `--hover-bg` < `--track`)과 반투명 흰색 테두리로 바꾼다. 배경 치환은 hex 대신 토큰으로 적는다 (`bg-white`→`--surface`, `bg-zinc-50`→`--bg`, `bg-zinc-100`→`--control`, `bg-zinc-200`→`--track`).
- §12 표 "진행률 게이지": 트랙 색 "보더 색" → `--track`.
- §12.4 `secondary`: 배경 `--control`, 다크 가장자리 `#07080b`.
- §12.4 칩: 비선택 배경 `--control`.
- §12.4 카드: 단어장 카드(`.vocab-card`) 플랫 예외와 버튼 위계(보조는 투명 + 테두리, 학습 버튼은 `--control` + 밝은 테두리).
- §12.4 명도 대비 표 아래: 다크 `--muted` 는 카드 위 8.3:1, 컨트롤 위 7.3:1.
- 개정 이력 1행 추가.

## 3. 남은 점검

- 실제 화면 확인(360px, 탐색·홈·통계·학습 설정·모달).
- 세그먼트 토글(학습 방식, 복습함 탭)은 선택 칸(`--surface`)이 바탕(`--control`)보다 어둡다. 이전에도 같은 방향이었고 이번에는 바꾸지 않았다.
