# 검토: 휠·터치 스크롤 결함 수정과 문서 개정안 (REQ-020, REQ-021)

- 작성일: 2026-11-26
- 상태: 코드 커밋 완료(`fbf7e0b`), `docs/` 개정 승인·반영 완료(2026-11-26). 기준선은 이번 변경분만 반영(node 661건, 커밋 상태에서 측정). 서체 라이선스 개정안을 반영할 때는 663건으로 갱신한다

## 1. 결함과 원인

**증상**: 마우스 휠과 모바일 터치 스와이프로 화면이 스크롤되지 않고, 스크롤바 드래그만 동작했다.

**원인** (`src/frontend/css/app.css`):

- `html, body` 에 `overflow-x: hidden` 과 `overscroll-behavior-y: contain` 이 함께 걸려 있었다.
- `overflow-x: hidden` 은 `overflow-y` 를 `auto` 로 바꾸므로 `body` 도 스크롤 컨테이너가 됐다.
- `body` 는 내용만큼 늘어나 자체 스크롤 거리가 없는데, `contain` 이 입력을 바깥 문서로 넘기지 않았다.

**수정**: `overscroll-behavior-y: contain` 과 `overflow-x: hidden` 은 `html` 에만 두고, `body` 는 `overflow-x: clip` 으로 바꿨다. `clip` 은 가로 넘침을 자르되 스크롤 컨테이너를 만들지 않는다.
