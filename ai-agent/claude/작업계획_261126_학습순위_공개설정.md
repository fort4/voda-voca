## 2. 사용자 결정 (2026-11-26)

1. 지표는 **서로 다른 단어 기준** 3종이다.
2. 화면은 **통계 안 전환**(`내 통계 | 순위`, `/stats/ranking`). 하단 탭은 4개 그대로다.
3. 본인이 비공개여도 **순위를 볼 수 있다**.
4. 기본값은 비공개, 공개 스위치는 마이페이지에 둔다.

## 3. 요구사항 초안

### REQ-172 학습 순위 조회 (S)

1. `GET /api/ranking?metric=` (비로그인 401). `metric` 은 `learned_words`(기본)·`week_words`·`week_days`, 그 밖은 422.
2. 지표
   - `learned_words`: 한 번 이상 맞힌 서로 다른 단어 수 (누적, 단어장 진행률과 같은 정의)
   - `week_words`: 최근 7일(한국 날짜, 오늘 포함)에 푼 서로 다른 단어 수 (정오 무관)
   - `week_days`: 최근 7일 중 학습한 날 수 (0~7)
3. 대상은 **공개한 사용자**뿐이다. 기록이 없어도 공개했으면 0 으로 보인다.
4. 선택한 지표의 내림차순. 값이 같으면 같은 순위(1, 1, 3)이고 닉네임 순으로 늘어놓는다. 상위 50명.
5. 항목은 `rank`, `nickname`, 지표 3종, `is_me` 만 담는다. **사용자 ID, 단어장 이름, 단어, 정답률은 싣지 않는다.**
6. 응답의 `me` 는 본인의 지표다. 50위 밖이어도 담으며, 비공개면 `rank` 가 null 이다.
7. 개인 단어장 학습도 센다.
8. (FR-053) 다른 사용자를 대상으로 하는 쓰기 API 는 없다. 순위 API 는 조회뿐이며 사용자 식별자를 입력받지 않는다.

### REQ-173 순위 공개 설정 (S)

1. `GET` / `PUT /api/users/me/ranking-visibility`, 본문 `{"public": true|false}` (불리언만, 그 밖은 422, 비로그인 401).
2. 가입자와 기존 사용자의 기본값은 **비공개**다.
3. 비공개로 바꾸면 다음 조회부터 남의 순위표에서 사라진다.
4. 마이페이지의 "순위 공개" 스위치에서 바꾼다. 닉네임과 학습 지표가 다른 사용자에게 보이고, 단어장·단어는 보이지 않음을 안내한다. 저장에 실패하면 이전 값으로 되돌린다.

- 개인 단어장에 쉬운 단어를 대량 등록하고 플래시카드에서 "알아요"를 누르면 순위를 올릴 수 있다. 반복 풀이만 막는다.
