## 3. ADR-018 학습 순위는 서로 다른 값을 세고 본인이 공개할 때만 보인다

- **배경**: 개인 단어장 도입(ADR-017) 뒤에도 사용자를 비교해야 한다. 정답률이나 푼 문항 수는 쉬운 단어 반복으로 쉽게 오른다.
- **결정**: ① 지표는 학습한 단어 수(누적), 최근 7일 푼 단어 수, 최근 7일 학습일이며 모두 `study_logs` 에서 읽는 시점에 센다. ② 개인 단어장 학습도 센다. ③ `users.ranking_public` 이 참인 사용자만 목록에 넣고 기본은 거짓이다. ④ 남에게는 닉네임과 지표만 보낸다. ⑤ 본인이 비공개여도 순위를 볼 수 있다.
- **대안**: 푼 문항 수(반복으로 부풀림), 표준 단어장만 집계(개인 단어장 사용자를 비교할 수 없음), 상호 공개한 사람만 열람(과제에 없는 제한), 요약 테이블(현재 규모에 불필요) — 기각.
- **결과**: 반복 풀이로는 오르지 않는다. 개인 단어장에 단어를 대량 등록하고 "알아요"를 누르면 올릴 수 있다. 단어를 삭제하면 지표가 줄어든다. 조회마다 공개 사용자의 전체 이력을 집계하므로 사용자가 많아지면 요약 테이블을 검토한다.

## 4. API 규격

| 메서드·경로 | 설명 |
| :--- | :--- |
| `GET /api/ranking?metric=` | `learned_words`(기본)·`week_words`·`week_days`. 401, 422 |
| `GET /api/users/me/ranking-visibility` | `{"public": false}`. 401 |
| `PUT /api/users/me/ranking-visibility` | 본문 `{"public": true}` (불리언만, 다른 필드 거부). 200 은 저장된 값. 401, 422 |

```json
{
  "metric": "learned_words",
  "items": [{"rank": 1, "nickname": "민지", "learned_words": 10, "week_words": 10, "week_days": 1, "is_me": false}],
  "total_public": 3,
  "me": {"public": false, "rank": null, "learned_words": 7, "week_words": 7, "week_days": 1}
}
```

정렬: 선택 지표 내림차순, 동점은 같은 순위(1, 1, 3)이고 닉네임 순(대소문자 무시). `items` 는 상위 50명, `total_public` 은 공개 사용자 전체 수.

## 5. 화면 규격

- 통계 상단 세그먼트 `내 통계 | 순위` (링크, `aria-current="page"`). 불러오는 중이나 기록이 없을 때도 보인다.
- 순위 화면: 지표 세그먼트 3칸 → 내 요약 카드(순위 또는 "비공개 상태예요", 지표, 마이페이지 이동 버튼) → 순위표("공개 N명", 지표 설명, 줄 목록, 비었을 때 안내, 50명 초과 안내).
- 줄: 순위 배지(1~3위 강조색), 닉네임(길면 말줄임), 선택 지표 값, 나머지 두 지표. 내 줄은 강조 테두리와 "나" 글자. 배경색은 바꾸지 않는다.
- 마이페이지 "학습 순위" 카드: 공개 범위 안내, 스위치(저장 실패 시 되돌리고 토스트, 읽기 실패 시 눌러 다시 시도), "순위 보기" 링크.
