# 검토 — 퀴즈 채점 직후 영단어 자동 발음 문서 개정안 (2026-11-26)

구현: `core/answer-speech.js`, `core/tts.js`(`prime`), `views/study-session-view.js`
검사: `tests/answer-speech.test.js`
상태: 2026-11-26 사용자 승인으로 문서와 화면 문구에 반영함 (구현 후 node 625건·55파일)

## 1. 새 규격

| 항목 | 내용 |
| :--- | :--- |
| 대상 | 퀴즈(4지선다·OX, 모든 출제 방향)의 채점 응답. 정답·오답과 관계없이 그 문항의 영단어를 읽는다. 플래시카드는 대상이 아니다 |
| 시점 | 효과음이 끝난 뒤 80ms 후. 효과음이 없으면 바로. 속도는 표제어와 같은 0.9 |
| 음소거 | 효과음 스위치(`voda.sound_muted`)를 끄면 자동 발음도 나지 않는다. 발음 버튼은 계속 동작한다 |
| 취소 | 다음 문항, 세션 중단, 문항 전환, 화면 정리 시 예약을 취소한다. 예약 시각에 탭이 숨겨져 있거나 음소거면 읽지 않는다 |
| 브라우저 제한 | 답을 누르는 클릭·키 입력 안에서 소리 없는 발화를 한 번 보내 이후 재생을 허용받는다 (iOS Safari) |
| 실패 처리 | REQ-125 ⑥ 과 같다 (학습 세션당 1회 토스트) |

## 2. 함께 고칠 화면 문구 (코드)

환경 설정 모달의 효과음 설명이 새 동작과 어긋난다 (`js/core/preferences-model.js`).

- 이전: `정답·오답·콤보·완료 소리를 들려줘요. 발음 듣기와는 별개예요.`
- 이후: `정답·오답·콤보·완료 소리와 퀴즈 자동 발음을 들려줘요. 발음 듣기 버튼은 별개예요.`

`preferences-model.test.js` 에 설명 문구 검사를 먼저 추가해 실패를 확인한 뒤 바꾼다.
