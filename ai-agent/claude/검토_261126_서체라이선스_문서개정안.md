## 1. 확인 결과

**Paperlogy Bold 는 SIL OFL 1.1 이며, 지금처럼 저장소와 컨테이너 이미지에 담아 배포할 수 있다. 서체 교체는 필요 없다.**

| 근거 | 내용 |
| :--- | :--- |
| 글꼴 파일 내장 `name` 테이블 | 라이선스 "SIL Open Font License, Version 1.1", 저작권 `Copyright © 2024 PT&` |
| 제작자 페이지 <https://freesentation.blog/paperlogyfont> | OFL. 글꼴 단독 판매·라이선스 변경을 뺀 상업적 이용·수정·재배포 가능 |
| 눈누·산돌구름 안내 페이지 | OFL, 웹사이트·서버 탑재(임베딩) 사용 가능 (제3자 안내) |
| 원본 동일성 | jsDelivr `gh/projectnoonnu/2408-3@1.0` 파일과 sha256 일치 |

남는 주의점:

- 내장 설명에 "프레젠테이션을 위한 파워포인트 전용 글꼴"이라는 문구가 있다. 소개 문구이며 라이선스 항목에는 용도 제한이 없다.
- 내장 설명상 글리프 원본은 G마켓 산스(한글)와 Montserrat(라틴)다. G마켓 산스의 OFL 표기는 제3자 안내(산돌구름)로만 확인했다.
