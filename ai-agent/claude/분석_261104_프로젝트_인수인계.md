## 1. 프로젝트 개요

- **서비스**: 모바일 우선 웹 영어 단어장. 다중 사용자가 단어장을 만들고 플래시카드·4지선다 퀴즈로 학습하고, 틀린 단어를 북마크·복습한다.
- **현재 버전**: v2.0.0 (정식 릴리즈). 이후 커밋은 v2.1 후보 개선.
- **환경**: Windows 11 + WSL2 (Ubuntu 24.04), Docker. DB는 컨테이너로만 연동.
- **사용자 현황**: 개발 DB에 사용자 1명, 학습 로그 약 58건. 실사용자는 아직 없음.

| 계층 | 기술 |
| :--- | :--- |
| 백엔드 | Python 3.12, FastAPI, SQLAlchemy 2.x (asyncmy), Pydantic 2, Alembic |
| DB | MySQL 8.0 (`utf8mb4`) |
| 인증 | 세션 쿠키(HttpOnly, SameSite=Lax) + bcrypt, 세션은 DB 저장. 닉네임이 고유키, 이메일 없음 |
| 프론트엔드 | HTML5, Vanilla JS (ES 모듈, JSDoc), 빌드 없음, 해시 라우팅, `textContent` 렌더링 |
| UI | Tailwind Play CDN, SweetAlert2, Lucide, 인라인 SVG 차트 |
| 테스트 | pytest, `node --test` |

```text
voda-voca/
├── CLAUDE.md, 개발방법론.md, README.md
├── docs/                 # 승인된 공식 산출물만 (v2.0 4종 + old/)
├── ai-agent/claude/      # 작업 일지, 검토서, 작업계획 (초안 공간)

├── src/frontend/         # index.html, css, js/{core,lib,views}, tests
└── docker/
```

## 2. 거버넌스 (기획 시 준수)

1. 최상위 정책 `개발방법론.md`, 실무 규칙 `CLAUDE.md`.
2. `docs/`는 승인된 공식 문서 전용. 신규 기획안은 `ai-agent/claude/`에 초안으로 쓰고 사용자 승인 후에만 승격한다.
   - 공식 문서명: `voda-voca_{EN_Name}_vX.X_YYMMDD.md`
   - 버전업: 구버전을 `docs/old/`로 `mv` 후 신규 파일로 `cp`하여 수정.
3. 작업 문서명: `{일지|검토|분석|작업계획}_{yymmdd}_{제목}.md`.
4. 요구사항이 모호하면 추정하지 말고 선택지와 함께 질문한다.
5. 사전 승인 필수: 아키텍처·DB 구조 변경, `git add/commit/push`, DB 상태 변경, 컨테이너 up/down.
6. TDD(Red → Green → Refactor). 간헐 실패는 숨기지 않고 보고 후 이슈 등록.
7. 신규 소스 파일 상단에 표준 헤더. 비밀 값은 `.env`로만 주입.
8. 모바일 뷰포트와 다크 모드 우선.

### 학습 지표 서버 집계 (#3)

- **문제**: 프론트가 `/study/logs` 최근 100건으로 지표를 계산해 진행률이 상한(200단어장 50%, 1,000제 10%)에 막히고, 연속 학습일·주간 차트가 과소 집계되고, 오답 복습이 맞혀도 반복 출제됐다.
- **결정(승인됨)**: 읽을 때 SQL 집계(방식 A), 스키마 변경 없음. 단어별 요약 테이블(방식 B)은 #1·#15 요구 미확정과 데이터 규모 이유로 보류. `study_logs`가 원본이라 B로 전환 가능.
- **지표 정의**: 오답 단어 = 단어별 마지막 결과가 오답 / 진행률 = 한 번이라도 맞힌 단어 ÷ 단어 수 / 정답률 = 누적 / 연속 학습일 = 하루 1문항 이상(한국 날짜, 오늘 안 풀었으면 어제부터).
- **구현**: 백엔드 `services/stats.py`, `services/study_log.py`, `GET /api/study/stats`. 프론트 `core/stats-view.js`(순수 함수), 대시보드는 요청 1건으로 감소, 이력·퀴즈 설정은 서버 값 사용, 죽은 코드 삭제.
- **테스트**: 백엔드 328건, 프론트 204건 통과(일지 기준, 이번 세션 재실행 안 함). 신규 테스트 먼저 작성 후 Red 확인. 실제 DB에서 오답 단어 18 → 14.
- **미확인**: 브라우저 실사용 확인 안 함, 성능 미측정.
- **사용자 체감 변화**: 정답률이 "최근 100문항"에서 "누적"으로 변경, 오답 복습 가능 단어 4개 미만 상태가 더 잦아짐(의도).
