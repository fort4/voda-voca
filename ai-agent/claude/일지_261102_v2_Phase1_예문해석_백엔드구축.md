## 2. 스키마 변경

### 2.1 마이그레이션 `4454ed2683cb`
- `upgrade()`: `words` 에 `example_meaning VARCHAR(500) NULL` 추가. 기존 행은 NULL.
- `downgrade()`: 컬럼 DROP. 저장된 해석은 함께 사라진다.
- 왕복 검증: 업그레이드 → 다운그레이드 → 업그레이드 모두 성공.

### 2.2 ORM과 스키마
| 대상 | 변경 |
| :--- | :--- |
| `models/word.py` `Word` | `example_meaning: Mapped[str \| None]` (String 500, nullable) |
| `schemas/word.py` `WordCreate` `WordUpdate` `WordOut` | `example_meaning: str \| None = None` |
| `schemas/study.py` `QuizQuestionOut` | `example_meaning: str \| None = None` |
| `schemas/study.py` `FlashcardOut` | 추가 (플래시카드에서도 뜻이 보이도록) |
| `schemas/bookmark.py` `BookmarkOut` | 추가 (북마크 목록에서도 보이도록) |

- 요청서의 `WordBase` 클래스는 현재 코드에 없다. 실제 구조는 `WordCreate`, `WordUpdate`, `WordOut` 세 클래스이므로 이 세 곳에 필드를 추가했다.
- `FlashcardOut`, `BookmarkOut` 은 요청서 목록에 없었지만, 예문을 보여 주는 모든 응답에서 해석이 빠지지 않도록 맞췄다.

### 2.3 예문 없음 규칙
예문이 없으면 예문 뜻은 저장하지 않는다. 세 경로에서 같은 규칙을 적용했다.
- **생성**: `WordCreate` 의 모델 검증이 예문이 비어 있으면 예문 뜻을 `None` 으로 바꾼다.
- **수정**: `update_word` 서비스가 수정 후 예문이 비어 있으면 예문 뜻을 `None` 으로 지운다. 예문만 지워도 해석이 따라 지워진다.
- **시드 로더**: 예문이 비어 있으면 해석을 버린다.

## 3. 시드 로더 (`services/seed.py`)

- CSV 헤더는 두 가지 중 하나여야 한다.
  - 3열: `term,meaning,example` (구형)
  - 4열: `term,meaning,example,example_meaning` (신형)
- 4열 파일에서 예문 뜻이 빈 칸이면 `None`. 열 자체가 없으면 `None`.
- UTF-8 BOM 을 허용한다 (`utf-8-sig`).
- 헤더가 두 형식 중 어느 것도 아니면 `ValueError` 로 메시지에 두 형식을 모두 보여 준다.
- JSON 항목은 `example_meaning` 키가 없어도 된다 (`item.get`).
- `SeedWord` 에 `example_meaning: str | None = None` 을 추가했다.

## 4. 시드 데이터와 번역 방식

### 4.1 대상
| 파일 | 건수 | 형식 |
| :--- | :-: | :--- |
| `beginner_200.json` | 200 | JSON, `example_meaning` 키 추가 |
| `intermediate_200.json` | 200 | JSON, `example_meaning` 키 추가 |
| `advanced_200.json` | 200 | JSON, `example_meaning` 키 추가 |
| `intermediate_1000.csv` | 1,000 | CSV 4열 |

### 4.2 방식
- 영문 예문을 한 건씩 읽고 자연스러운 한국어 문장으로 옮겼다. 자동 번역 도구는 쓰지 않았다.
- 번역은 `표제어 TAB 번역` 형식의 임시 파일(스크래치패드)에 100건 단위로 작성했고, 병합 전에 다음을 검증했다.
  - 원본과 번역의 표제어 순서가 한 건씩 일치하는지 (어긋나면 중단)
  - 번역이 비어 있지 않은지
  - 한자(CJK)가 섞이지 않았는지 (검출 2건을 고쳤다. "含意", "灣")
  - 길이가 500자 이하인지
- 병합 후 표제어, 뜻, 예문은 HEAD 와 비교해 한 글자도 바뀌지 않았다.

### 4.3 한계
- **사람 검토가 필요하다.** 1,600건은 작성자가 직접 옮긴 것이므로, 표현이 어색하거나 문맥에 맞지 않는 항목이 있을 수 있다. 특히 다의어와 전문 용어의 뜻 선택을 검토해야 한다.
- 번역은 예문 문장 자체의 해석이다. 표제어의 뜻(`meaning`)과 같은 말이 아니다.
- 예문의 활용형(`accompanied`, `boundaries` 등)은 번역에서 그대로 살렸다.

- 프론트엔드 테스트 155건 통과 (`quiz-flow` 해석 전달 테스트 1건 추가).
