## 3. 핵심 기술 결정과 근거
- **`BEGIN IMMEDIATE`**: SQLite 기본(DEFERRED)은 읽기로 시작한 트랜잭션이 쓰기로 올라갈 때 다른 커밋이 끼면 `busy_timeout` 과 무관하게 즉시 `database is locked`. 인증이 먼저 읽으므로 실제 발생한다(일반 `BEGIN` 으로 바꿔 테스트가 실패함을 확인). `FOR UPDATE` 대체.
- **PK/FK 는 `Integer`**: SQLite 는 `INTEGER PRIMARY KEY` 만 rowid 별칭(자동 증가). `BigInteger` 금지(`test_system_models.py` 가 고정).
- **시간 기본값 `strftime('%Y-%m-%d %H:%M:%f000','now')`**: `%f` 는 밀리초 3자리라 `000` 을 붙여 6자리 마이크로초로 맞춘다. 3자리면 SQLAlchemy 가 0.123초를 0.000123초로 읽는다.
- **`NOCASE`**: 닉네임·표제어·slug. 악센트 무시는 사라졌고 시더가 자체 정규화.
- **무결성 오류 판별**: MySQL 은 제약 이름이 메시지에 있었으나 SQLite 는 `UNIQUE constraint failed: 테이블.컬럼` / `FOREIGN KEY constraint failed` 만 준다. 외래키는 "인증된 사용자 기준 걸릴 수 있는 FK 는 단어뿐"이라는 가정으로 단어 삭제로 해석(`db/errors.py`).
- **API 기준 경로**: 서버가 `/2026/voca-<학번>/` 접두사 아래로 옮기고 nginx 가 **리터럴 문자열만** 치환한다. 상대경로 `api` 는 주소가 슬래시 없이 열리면 어긋나므로, 모듈 위치(`import.meta.url`)에서 앱 루트를 계산한다. 라우팅은 해시라 무관.
- **entrypoint**: `alembic upgrade head` 후 `exec "$@"`. `.dockerignore` 가 `docker/` 를 통째로 제외하므로 루트에 둔다.
