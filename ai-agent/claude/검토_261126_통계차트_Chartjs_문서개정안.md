# 검토 — 통계 차트(Chart.js)와 화면 공통 시각 규칙 문서 개정안 (2026-11-26)

상태: 2026-11-26 사용자 승인으로 `docs/` 와 README 에 반영함
계기: 사용자 요청 — ① 같은 모양의 막대가 반복되는 통계 화면을 Chart.js 등으로 시인성 좋고 화려하게, ② 홈 등 다른 화면의 막대와 UI 도 같은 방향으로 통일감 있게 (§6).

## 1. 결정 (ADR-015 초안): 차트 라이브러리로 Chart.js 4.6.2 채택

- **맥락**: REQ-132 는 "외부 차트 라이브러리는 쓰지 않는다" 였고, 추이는 모두 같은 진행 막대로 그려 구분이 어려웠다.
- **결정**: Chart.js 4.6.2 UMD(MIT)를 `src/frontend/vendor/chart.js-4.6.2/` 에 자체 호스팅한다. npm 배포본의 sha512 를 대조했다. 실행 중 인터넷은 필요 없고 빌드 파이프라인도 늘지 않는다.
- **대가**: 첫 화면에서 약 213KB(압축 전) 스크립트를 더 받는다. canvas 는 화면낭독기가 읽지 못해 표 보기와 키보드 탐색을 함께 둔다.
- **대안**: 인라인 SVG 직접 구현(의존성이 없지만 말풍선·모션·반응형을 모두 만들어야 한다).

## 2. 요구사항 명세 (`분석_261125_요구사항명세서 v2.3.md`)

- **REQ-132 개정**: "인라인 SVG 막대 차트" → "Chart.js 막대 차트". "외부 차트 라이브러리는 쓰지 않는다" 삭제, "라이브러리는 vendor/ 에서 같은 출처로 제공한다" 추가. 오늘 강조·"오늘" 표시·누르거나 포커스하면 개수 표시는 유지한다(키보드는 좌우 화살표).
- **REQ-166 신설 (통계 시각화, S)**: ① 회차별 정답률은 면적 선 그래프, 날짜별 정답률은 세로 막대, 세로축은 0~100%. ② 회차 제목 옆에 최근 정답률과 직전 대비(아이콘 + 부호 있는 글자), 날짜 제목 옆에 문항 수 가중 평균. ③ 모든 차트에 "표로 보기". ④ 라이브러리를 못 쓰면 표를 펼친다. ⑤ 테마를 바꾸면 새 색으로 다시 그리고, 화면을 떠나면 차트를 정리한다. ⑥ 동작 줄이기 설정이면 애니메이션이 없다. ⑦ 요약 카드에 지표별 아이콘(배경은 표면색), 누적 정답률 고리. 자주 틀리는 단어(순위 배지)와 단어장 진행률은 서로 다른 색의 막대.
- §7 추적: REQ-132 구현 파일 `core/weekly-chart.js` → `core/chart-model.js`, `core/chart-set.js`, `views/components/chart-panel.js`. REQ-155·166 도 같은 파일을 쓴다. 개정 이력 1행.

## 3. UI/UX 설계서 (`설계_261105_UIUX설계서 v2.2.md`)

- §3.5: "요약 카드 2개" → 4개(색 아이콘, 정답률 고리). 주간 차트와 성적 추이 설명을 위 REQ-132·166 내용으로 바꾼다. "진행 막대(`progress-bar.js`)로 그린다" 삭제.
- §12: "차트 막대 (v2.0)" 행의 SVG 설명을 Chart.js 로 바꾸고, "오늘 뱃지" 행은 "x축 라벨 아래 `오늘`" 로 바꾼다.

## 5. 확인 상태

- 자동: 프론트 `node --test` 658건 통과. 백엔드 pytest 895건 통과(4건 건너뜀)는 §6 작업 전에 실행했고, §6 은 백엔드를 바꾸지 않았다.
- 화면: 헤드리스 Chromium + 가짜 API 데이터로 360px 라이트·다크, 768px 다크, 데이터가 1건/0건인 경우를 확인했다. 실제 서버 데이터와 실기기 터치는 확인하지 않았다.

## 6. 화면 공통 시각 규칙 (UI/UX 설계서 개정, REQ-167 초안)

REQ-167 신설 (화면 공통 시각 규칙, S): 아래 규칙. 기능·API·데이터 변경 없음. 검사는 `ui-unified.test.js` (TC-167).

| 항목 | 규칙 | 설계서 위치 |
| :--- | :--- | :--- |
| 의미 색 `.tone-*` | 학습=남색(accent), 오늘 활동·북마크=주황(activity), 단어=청록(words), 오답=빨강(wrong), 달성=초록(ok) | §12 신설 |
| 진행 막대 | 앱 전체 10px 한 모양, 그라데이션. 의미 색 progress·goal·ok·wrong. 홈·탐색은 오른쪽에 퍼센트 | §12 "진행률 게이지" (6px, 단색 규칙 대체) |
| 카드 제목 | 색 아이콘 배지 + 제목 (`card-heading.js`). 카드 배경은 한 가지 표면색이며 색 번짐·그라데이션을 쓰지 않는다 (사용자 의견 반영) | §12.4 |
| 세그먼트 | 학습 방식·출제 설정·복습함 탭이 같은 모양. 선택 칸은 `--accent-soft` + 강조색 안쪽 테두리 | §12.13 수동 점검 ③ 해소 |
| 홈 | "단어장 바꾸기" ghost → secondary(전체 폭). 연속 학습일은 불꽃 아이콘 알약(이모지 폐지). 목표를 채우면 카드와 막대가 초록 | §3.2, §12.5 홈 행 |
| 탐색 | 학습 중 카드는 강조색 테두리. 버튼 폭 2:3 (360px 에서 "이 단어장으로 학습" 한 줄) | §3.3, §12.4 `.vocab-card` |
| 복습함 | 출처 색(북마크 주황, 틀린 단어 빨강)의 안내 카드 아이콘과 목록 왼쪽 띠 | §3.4 |
| 마이페이지 | 카드 제목 아이콘 | §3.8 |
| 학습 결과 | 지표 칸에 색 아이콘(칸 배경은 표면색, 360px 에서 세 칸 한 줄), 틀린 단어 왼쪽 띠 | §3.6 |

막대 의미 색 토큰 (라이트 / 다크): goal `#d97706→#ea580c` / `#f59e0b→#fb923c`, ok `#059669→#047857` / `#10b981→#34d399`, wrong `#ea580c→#dc2626` / `#fbbf24→#f87171` (§3 표의 wrong 라이트 값은 이 값으로 바뀐다).

바꾸지 않은 곳: 로그인·회원가입, 단어 미리보기 시트, 설정 모달, 상단바·하단 탭바.
