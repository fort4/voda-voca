## 2. 요구사항 (안)

### REQ-159 관리자 권한 (M)
- 닉네임이 `admin`(대소문자 무시)인 계정이 관리자다. ID 는 고정이며 바꾸지 않는다.
- `admin` 닉네임은 예약어다. 일반 가입과 중복 확인에서 사용할 수 없다.
- 관리자 계정은 서버가 시작할 때 없으면 만든다. 초기 비밀번호는 `admin1234` 다(11-26 결정). 이미 있으면 건드리지 않아, 바꾼 비밀번호가 재시작 뒤에도 유지된다.
- 알려진 위험: 공개 저장소의 기본값이므로 바꾸기 전에는 누구나 관리자로 로그인할 수 있다. CLAUDE.md §5.3(비밀값 하드코딩 금지)의 예외로 결정 기록에 남긴다.
- 관리자 계정은 탈퇴할 수 없다 (기존 `DELETE /api/auth/me` 에서 거부).
- 관리 API 는 비로그인 401, 일반 사용자 403 이다. 권한은 서버가 요청마다 판정한다.
- 내 정보 응답에 관리자 여부를 실어 화면이 관리 기능의 노출을 정한다. 화면 숨김은 권한 검사를 대신하지 않는다.
- 계정 준비 방법을 README 에 적는다.

### REQ-160 관리자 단어장 (M)
- 관리자는 새 단어장을 만든다 (제목 필수, 설명·카테고리·레벨 입력). `slug` 는 서버가 만들며 시드 `slug` 와 겹치지 않는다.
- 만든 단어장은 모든 사용자의 카탈로그에 보이고 학습 단어장으로 고를 수 있다.
- 시드 로더는 관리자 단어장을 바꾸지 않는다.

### REQ-161 관리자 단어 등록·수정·삭제 (M)
- 등록: 표제어(100자)·뜻(200자) 필수, 예문·예문 뜻(각 500자) 선택. 앞뒤 공백 제거, 예문이 없으면 예문 뜻도 저장하지 않는다.
- 같은 단어장 안의 표제어 중복(대소문자 무시)은 409 다.
- 대상 단어장은 관리자 단어장과 표준 단어장 모두다.
- 수정·삭제는 관리자 등록 단어만 가능하다. 시드 단어에 대한 요청은 403 이다.
- 삭제 전 확인 모달에서 **모든 사용자의 해당 단어 학습 이력·진도·북마크가 함께 지워짐**을 알린다. 그 결과 통계 값이 달라진다.
- 진행 중인 세션에서 삭제된 단어에 답하면 409 다 (기존 동작 유지).
- 등록·삭제와 같은 트랜잭션에서 `total_words` 를 갱신한다.

### REQ-162 CSV 일괄 등록 (M)
- 관리자 전용. 단어장 하나를 골라 올린다.
- 상한: 1회 500행(헤더 제외), 파일 512KB.
- 인코딩: UTF-8 (BOM 허용). 아니면 거부하고 "CSV UTF-8" 형식으로 저장하라고 안내한다.
- 필수 열: 표제어, 뜻 / 선택 열: 예문, 예문 뜻. 길이 한도는 REQ-161 과 같다.
- 상한 초과·형식 오류는 파일 전체를 거부하고 오류 행 번호를 알려 준다.
- 중복 표제어(같은 단어장, 대소문자 무시)는 건너뛰고 건수를 보고한다. 오류가 아니다.
- 요청 1회, 트랜잭션 1회로 처리한다.
- 결과: 등록 건수, 건너뛴 건수.

### REQ-163 단어 검색 (M)
- 로그인한 사용자는 단어장 안에서 표제어 또는 뜻의 일부로 검색한다.
- 영문 대소문자를 구분하지 않는다. `%`, `_`, `\` 는 일반 문자로 처리한다 (REQ-113).
- 결과는 단어 목록(REQ-141)과 같은 형식·페이지 나눔이다. 빈 검색어는 전체 목록이다.
- 폐기된 REQ-009 의 검색 부분을 잇는다.

### REQ-164 비밀번호 변경 (M)
- 로그인한 관리자는 본인 비밀번호를 바꾼다 (모든 사용자 제공 여부는 §5).
- 현재 비밀번호, 새 비밀번호, 새 비밀번호 확인을 받는다. 새 비밀번호 규칙은 가입(REQ-001)과 같다.
- 현재 비밀번호가 틀리면 거부하고 시도 횟수를 제한한다.
- 성공하면 지금 세션을 뺀 본인의 다른 세션을 만료시킨다.

## 4. 설계에 넘길 사항

1. 마이그레이션 0003: `system_words`, `system_vocabularies` 에 출처 컬럼(`seed`/`admin`, 기본 `seed`)을 추가한다.
   - **테이블을 batch 로 재작성하지 않는다.** `COLLATE NOCASE` 가 사라질 수 있고, 재작성 중 부모 테이블 삭제가 학습 이력의 `ON DELETE CASCADE` 를 일으킬 위험이 있다. `ADD COLUMN` 만 사용하고 두 가지를 테스트로 확인한다.
2. 시드 로더: 관리자 단어에는 "시드에 없는 단어" 경고를 내지 않는다.
3. 새 단어는 `order_index` 를 끝에 붙인다. 미학습 충원이 이 순서를 따르므로, 표준 단어장에 더한 단어는 기존 미학습 단어 뒤에 출제된다.
4. 업로드는 CSV 본문을 그대로 보내면 `python-multipart` 의존성 추가가 필요 없다 (현재 `requirements.txt` 에 없음).
5. API 경로는 `import.meta.url` 기준 규칙을 따른다.
