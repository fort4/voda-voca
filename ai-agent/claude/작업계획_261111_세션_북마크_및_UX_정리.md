# 작업계획 — 세션 중 북마크(REQ-148 신설)와 세션 화면 UX 정리 (v2.2 후속)

- 작성일: 2026-11-11
- 상태: 구현 완료, `docs/` 반영 (사용자 승인 2026-11-11)

## 1. 배경

1. 퀴즈·플래시카드를 진행하는 중에는 단어를 북마크할 방법이 없었다. 북마크 API(REQ-017)는 이미 있으나 단어 목록 화면에서만 쓸 수 있었다.
2. 퀴즈 해설 시트에 단어 듣기 버튼이 있었으나 세션 헤더에 같은 버튼이 이미 있어 중복이었다.
3. 플래시카드 "알아요"의 효과음은 퀴즈 정답음과 같아 UX 상 중복이었다.

## 2. 결정 (사용자 확인 2026-11-11)

| 항목 | 결정 |
| :--- | :--- |
| 북마크 버튼 위치 | 퀴즈 카드·플래시카드 **오른쪽 위** (44px 아이콘 버튼) |
| API | `SessionItemOut` 에 `bookmarked: bool` 추가 (출제 시점의 사용자 북마크 여부). DB 마이그레이션 없음 |
| 해설 시트 | 단어 듣기 제거, 예문 듣기는 유지 |
| 플래시카드 효과음 | "알아요"·"헷갈려요" 모두 무음 (콤보 마일스톤도 퀴즈에서만). 완료 팡파레는 유지 |

## 3. 설계

### 3.1 백엔드
- `schemas/learning_session.py`: `SessionItemOut.bookmarked`(기본 false).
- `services/learning_session.py`: `_bookmarked_ids` 가 출제한 문항의 `word_id` 로 `bookmarks` 를 한 번에 조회(`IN`)하고, 일반 세션·복습 세션 두 생성 경로가 `_item` 에 넘긴다.
- 값은 출제 시점 기준이며 세션 스냅샷(`quiz_sessions.questions`)에는 저장하지 않는다 (북마크는 세션 밖에서도 바뀌는 값이다).

### 3.2 프론트엔드
- `core/bookmark-store.js` (`createBookmarkStore({api})`): `seed`(모르는 단어만 채움), `toggle`(낙관적 갱신 → `PUT`/`DELETE /bookmarks/{id}`, 실패 시 롤백 후 오류 전달, 같은 단어 진행 중이면 무시), `subscribe`.
- `views/components/bookmark-button.js`: 44px `btn-icon star-toggle`, `aria-pressed`·라벨, 클릭 전파 차단(카드 뒤집힘 방지), 저장소 구독으로 스스로 갱신.
- `views/study-session-view.js`: 세션 화면마다 저장소 하나. 퀴즈 카드(`.session-card`)와 플래시카드(`.flip-stage`, 뒤집히는 카드의 **형제**)에 `.bookmark-slot` 을 둔다. 실패 시 오류 토스트.
- `css/app.css`: `.bookmark-slot`(absolute, 오른쪽 위), `.flip-stage`·`.session-card` 를 기준 위치로.
- `feedback-sheet.js`: 표제어 옆 `speakButton` 제거.
- `core/combo-model.js`: `soundCueFor` 가 플래시카드 답변에는 `null`.
