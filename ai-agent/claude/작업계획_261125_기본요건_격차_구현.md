## B 단계 설계 메모 (사용자 승인, 2026-11-25)

결정: ① 형식은 4지선다 + **OX** (단답형은 채점이 모호해 제외) ② 방향·형식은 **퀴즈를 시작할 때마다 고른다**(요청 파라미터, 사용자 설정 컬럼은 추가하지 않는다) ③ 마이그레이션 0002 로 `quiz_sessions`·`study_logs` 에 컬럼 추가.

- 요청 `POST /api/study/sessions`: `direction`(en_to_ko 기본 | ko_to_en | mixed), `format`(choice 기본 | ox). 플래시카드에는 적용하지 않는다(기본값으로 저장).
- 문항 스냅샷(JSON)에 `direction`(문항별 실제 방향, mixed 는 문항마다 무작위), `format`, `prompt`(화면에 보일 문제 문구), `proposed`(OX 가 제시하는 보기), `meaning` 을 추가한다. 옛 스냅샷은 키가 없으면 영→한·4지선다로 읽는다.
- 한→영은 정답인 영단어가 `term` 에 있으므로 출제 응답의 `term` 을 null 로 하고 `prompt`(뜻)만 준다. 채점 응답에서 공개한다.
- OX: 제시 보기가 맞을 확률 50%, 틀린 보기는 같은 단어장의 다른 단어의 뜻(영→한) 또는 단어(한→영). `choices=["O","X"]`, 답은 `choice_index` 0(O)·1(X). 범위를 벗어난 번호는 400.
- DB: `quiz_sessions.direction`(en_to_ko|ko_to_en|mixed)·`format`(choice|ox), `study_logs.direction`(en_to_ko|ko_to_en)·`format`(choice|ox). 기존 행은 en_to_ko·choice. 문항 단위 이력이므로 mixed 도 로그에는 실제 방향을 적는다.
- 화면: 홈의 퀴즈 모드에서 방향·형식 선택(세그먼트), 세션 화면은 prompt·형식에 따라 문제 카드와 선택지(OX 는 2버튼)를 그린다. 키보드 1~4(OX 는 1·2, O/X 키).
