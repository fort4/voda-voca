## A 단계 설계 메모

- 자주 틀리는 단어: `study_logs` 의 오답 행 수로 센다(FR-034). 오답 복습(`wrong_word_ids`, "마지막 결과가 오답")과 달리 맞혀도 줄지 않는다. 횟수 동률이면 최근 오답, 그다음 단어 ID 순.
- 회차별 정답률: `quiz_sessions` 중 mode=quiz 이고 답한 문항 수 ≥ 문항 수인 세션만. 학습 세션 화면의 완료 기준(`is_finished`)과 같다. 회차 번호는 전체 기준을 유지한 채 최근 N회만 내려준다.
- 날짜별 정답률: 한국 날짜(UTC+9) 기준, 퀴즈 모드 문항 이력만(플래시카드 제외), 기록이 있는 날만.
- 스키마 변경 없음(마이그레이션 불필요, `alembic check` 통과).
