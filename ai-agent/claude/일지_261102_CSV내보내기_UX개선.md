## 3. 문제와 원인

- **문제**: 계정 드롭다운의 "내 단어장 백업"을 누르면 확인 없이 바로 전체 파일이 내려받아졌다.
- **원인**: 드롭다운 항목이 `downloadBackup()`을 직접 호출했다. 범위를 고르거나 취소할 자리가 없었다.
- **해결**: 항목은 내보내기 모달을 열고, 실제 다운로드는 모달의 [내보내기]에서만 실행한다.

---

## 4. 설계 판단

### 4.1 내보내기 모달 (`js/app.js`)
- SweetAlert2로 연다. 범위는 라디오 두 개다.
  - **전체 단어장 합본**: 모든 단어장을 하나의 파일로. 헤더 `단어장,표제어,뜻,예문,예문 뜻`
  - **개별 단어장 선택**: 셀렉트 박스에서 고른 단어장 하나. 헤더 `표제어,뜻,예문,예문 뜻`
- 개별 선택은 단어장이 하나도 없으면 비활성화한다. 셀렉트는 "개별 선택"일 때만 활성화한다.
- 단어장 목록은 모달을 열 때 받는다. 실패하면 모달 대신 토스트로 알린다.
- [취소]는 `isConfirmed`가 거짓인 경우 그대로 끝난다. 다운로드 코드에 도달하지 않는다.
- 파일 규격 안내 문구를 넣었다 (UTF-8 with BOM, 엑셀 호환).

### 4.2 개별 단어장 카드 (`js/views/wordbooks.js`)
- 우측 열에 `download` 버튼을 추가했다. 수정(pencil), 내보내기(download), 삭제(trash-2) 순서다.
- 확인 문구는 요구사항 그대로다: "이 단어장('[이름]')의 단어 N개를 CSV 파일로 내보내시겠습니까?"
- N은 목록의 `word_count`를 쓴다. 확인 뒤에 단어를 받아 파일을 만든다.
- 파일 이름은 `[단어장_이름]_YYYYMMDD.csv`다. 공백은 밑줄로 바꾸고, `/ \ : * ? " < > |`와 제어 문자는 지운다.

### 4.3 일괄 등록과의 호환 (`js/lib/csv.js`) — 요구사항과 충돌했던 부분
- **문제**: 요구사항은 개별 단어장 파일의 헤더를 `표제어,뜻,예문,예문 뜻`으로 정했다. 그런데 기존 일괄 등록 파서는 **세 번째 칸 뒤의 값을 열 초과 오류로 처리했다**. 예문 뜻이 있는 단어가 하나라도 있으면 내보낸 파일을 다시 가져올 수 없었다.
- **해결**: 헤더가 `표제어,뜻,예문,예문 뜻`인 경우에만 네 번째 칸을 예문 뜻으로 읽는다.
  - 예문 뜻은 `example_meaning`으로 전송한다. 백엔드의 `WordBulkCreate`는 이미 이 필드를 받는다.
  - 예문 뜻이 비어 있으면 키 자체를 보내지 않는다. 기존 테스트의 본문 비교가 그대로 통과한다.
  - 500자를 넘으면 행 오류다.
- **유지한 동작**: 헤더가 없거나 다른 헤더인 파일의 네 번째 칸은 여전히 열 초과 오류다. 기존 테스트(`세 번째 칸 뒤에 값이 있으면 열 초과`)가 이 동작을 고정하고 있어서, 이 경계를 바꾸지 않았다.
- 가져오기 화면의 미리보기 표에는 예문 뜻을 아직 보여 주지 않는다. 전송 본문에는 들어간다.

### 4.4 전체 백업 형식 유지
- 전체 합본은 기존 `buildBackupCsv`와 헤더 `단어장,표제어,뜻,예문,예문 뜻`을 그대로 쓴다.
- 전체 합본은 가져오기로 다시 읽을 수 없다. 단어장 열이 있어서 일괄 등록의 3~4열 규격과 맞지 않는다. 이는 기존 설계(백업 용도)와 같다.

### 4.5 다운로드 공통 경로
- `downloadCsv(fileName, body)`로 BOM 부착과 Blob 생성을 한 곳에 모았다.
- 전체 합본(`downloadBackup`)과 개별 단어장(`downloadWordbook`)이 같은 함수를 쓴다.

## 7. 브라우저 확인 가이드 (이 환경에서 수행하지 못함)

1. **드롭다운 클릭**: 계정 메뉴의 "내 단어장 백업"을 누르면 **파일이 바로 받아지지 않고** 모달이 뜨는지 확인한다.
2. **모달 기본값**: "전체 단어장 합본"이 선택되어 있고, 셀렉트 박스는 비활성인지 확인한다.
3. **개별 선택**: "개별 단어장 선택"을 고르면 셀렉트가 활성화되고, 단어장 이름이 목록에 있는지 확인한다.
4. **취소**: [취소]를 누르면 아무 파일도 받아지지 않는지 확인한다.
5. **합본 내보내기**: [내보내기] 후 `보다보카-단어장-YYYYMMDD.csv`가 받아지고, 헤더가 `단어장,표제어,뜻,예문,예문 뜻`인지 확인한다.
6. **개별 내보내기 (모달)**: 개별 단어장을 고르고 내보내면 `[단어장_이름]_YYYYMMDD.csv`가 받아지고, 헤더가 `표제어,뜻,예문,예문 뜻`인지 확인한다.
7. **카드 내보내기**: 단어장 카드의 다운로드 아이콘을 누르면 "이 단어장('…')의 단어 N개를 CSV 파일로 내보내시겠습니까?"가 뜨는지 확인한다. 취소하면 아무 일도 없다.
8. **엑셀**: 내보낸 파일을 엑셀로 열어 한글과 쉼표가 들어간 뜻(예: "배, 과일")이 깨지지 않는지 확인한다.
9. **다시 가져오기**: 개별 단어장 파일을 다른 단어장의 "일괄 등록"으로 가져온다. 예문 뜻 열이 있어도 "열이 세 개를 넘습니다" 오류 없이 미리보기에 나타나는지 확인한다.
10. **다크 모드**: 모달과 카드 버튼이 다크 모드에서도 읽히는지 확인한다.
