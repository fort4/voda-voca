## 학습 메모
- 한→영은 `term` 뿐 아니라 예문(`I like apple.`)에도 정답이 있다. UI 에서 숨기는 것은 네트워크 응답으로 새므로 서버가 `context` 를 null 로 보내게 했다(테스트를 먼저 써서 Red 확인).
- `mixed` 는 요청 값이고 이력에는 실제 방향을 적어야 문항 단위 분석(FR-026)이 의미가 있다.
- autogenerate 는 CHECK 제약을 못 잡아 0002 에 수동으로 추가했다.
