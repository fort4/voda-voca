## 1. 복습함 "null" 글자 표시 제거
- **증상**: 북마크·틀린 단어가 모두 로드된 상태(또는 비어 있을 때) 목록 아래에 "null" 글자가 보임.
- **원인**: `review-view.js`가 `this.body.append(..., null)`을 호출. DOM 네이티브 `append`는 `null`을 문자열 "null"로 바꿔 넣음.
- **조치**: `dom.js`의 `appendNodes()`(null/undefined/false 제외)로 교체.
- **회귀 방지**: `tests/review-view-null.test.js` — 소스에 `this.body.append(` 재유입 방지 검사.
- 참고: 같은 패턴을 다른 화면에서 점검했으나 모두 요소만 넘기고 있어 해당 없음.

### 3.2 카드 전환 연출 개선
- **문제 1**: 화면 전체를 매번 다시 그려 카드가 애니메이션 없이 바뀌고 깜빡임.
- **조치 1**: 평가한 카드를 옆으로 밀어냄(알아요 → 오른쪽, 헷갈려요 → 왼쪽, 180ms). 다음 카드는 한 번만 아래에서 올라옴. CSS는 `css/app.css`(`card-exit-*`, `card-enter`).
- **문제 2**: 밀려난 뒤 서버 응답까지 빈 자리가 생겨 "사라졌다 튀어나오는" 느낌.
- **조치 2**: 연출이 끝나면 응답을 기다리지 않고 다음 카드를 앞면으로 미리 표시. 응답 후 실제 전환 시에는 같은 카드라 연출 반복 없음. 전환 중 뒤집기 차단, 전송 실패 시 원래 카드 복원.
- **한계**: 마지막 카드는 다음 카드가 없어 결과 화면까지 빈 상태. 응답이 느리면 보일 수 있음(후속 과제: 로딩 표시).
- 브라우저 실기 확인은 하지 못함 — 모바일 뷰포트에서 체감 확인 필요.
