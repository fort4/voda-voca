# 모바일 실기기 점검 체크리스트 (v2.2)

| 항목 | 내용 |
| :--- | :--- |
| 목적 | 브라우저가 없는 환경이라 자동 검증이 안 되는 시각·터치 항목을 사용자가 직접 확인 |
| 기준 | 뷰포트 360px(작은 폰)과 390px, 라이트·다크 모드 각각 |
| 결과 기록 | 각 항목 `[ ]` 에 체크하고, 문제는 "증상 / 화면 / 기기"를 적어 전달 |

## 1. 세션 북마크 (REQ-148)
- [ ] 360px 퀴즈 카드: 오른쪽 위 북마크 버튼이 표제어·품사 태그와 겹치지 않는다
- [ ] 360px 플래시카드 앞면: 북마크 버튼과 "탭해서 뒤집기" 안내가 겹치지 않는다
- [ ] 플래시카드 뒷면: 뒤집은 뒤에도 오른쪽 위에 버튼이 있고, 앞·뒷면 상태가 같다
- [ ] 북마크 버튼을 눌러도 카드가 뒤집히지 않는다
- [ ] 터치 직후 호박색이 hover 에 덮이지 않고 유지된다
- [ ] 다크 모드에서 북마크 켬/끔 색이 구분된다

## 2. 플래시카드 뒷면 (이번 수정, da69dd2)
- [ ] 예문과 예문 해석 사이 간격이 해설 시트와 비슷하게 좁다
- [ ] 예문이 길어 여러 줄이어도 발음 버튼(우측)과 겹치지 않는다
- [ ] 예문이 없는 단어는 해석만 정상 표시된다

## 3. 표시 요소
- [ ] 품사 칩·IPA 글리프가 깨지지 않는다 (ə, ɪ, ʃ, ŋ, ˈ 등이 있는 단어)
- [ ] 복습함 행: 표제어 · 품사 · /발음기호/ 가 좁은 화면에서 줄바꿈되고 예문은 보이지 않는다
- [ ] 제목·큰 글씨가 Paperlogy 로 보이고, 로딩 전 깜빡임이 거슬리지 않는다

## 4. 설정 모달
- [ ] 계정 메뉴: 학습 설정(book-open) → 환경 설정(settings) → 로그아웃 순서
- [ ] 환경 설정: 효과음·다크 모드 스위치가 누르는 즉시 적용되고 닫기만 있다
- [ ] 학습 설정: 퀴즈/플래시카드/일일 목표 값이 저장되고 홈 목표에 반영된다
- [ ] 모달 등장이 통통 튀지 않는다 (오버슈트 없음)
- [ ] 로그인 화면에서는 다크 모드를 못 바꾸는 것이 의도임을 인지 (저장값·시스템 설정 적용)

## 5. 배포 전 확인
